# ShopEasy — QA Testing Project

## Project Overview

ShopEasy is a fictional e-commerce application created for a practical Quality Assurance (QA) testing project.

The project simulates a software testing process to demonstrate QA skills acquired during my QA Analyst training.

## Project Objectives

- Practice software testing techniques.
- Analyze and understand software requirements.
- Design and execute test cases.
- Identify and report software defects.
- Perform API testing.
- Practice basic SQL queries.

## Application Features

- User Registration
- User Login
- Shopping Cart
- Order Checkout

## Tools and Technologies

- GitHub
- Microsoft Excel
- Jira
- Postman
- SQL
